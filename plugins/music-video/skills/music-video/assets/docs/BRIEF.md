## A. 试片任务书（定画风；每个方向一个分支，并行）

# 试片：《歌名》· <方向名>

背景一段：哪首歌、用户想要什么、已经同意的构思、这几个方向会并排给用户挑，所以比的是画风，故事节拍尽量一样。

### 硬规则
- 不写歌词原文：代码、注释、文档、报告、你自己的推理里都不写。字幕从 `/assets/lyrics/lyrics.json` 读；提到某句用行号。
- 确定性：`renderAt(t)` 是 t 的纯函数，或者是从片段开头按固定步长重算的模拟。不用 `Math.random`、`Date.now`、`performance.now`、`THREE.Clock`。挑几帧在两次运行里渲，逐字节比对。
- 颗粒不用 `fract(sin(dot(p, …)) * 43758.5453)` 一类在整数像素坐标上的哈希（会成 3 像素的网格），用整数哈希；原尺寸、拉大对比度看一块空背景。
- 第 0 帧是一幅完成的画，能直接当封面：不是黑场，不是等东西出现的空画面。
- 用户这次已经否掉的：（例：直接渲染的 3D 人物、Q 版小人……）
- 不改共用文件（`render.mjs`、`look_tests/clip.json`、`assets/`）。要改就复制到自己目录，或在报告里说。

### 格式和工具
- 分辨率、帧率、横竖和理由。片段：原曲 a–b 秒，N 帧（`look_tests/clip.json`，由 `tools/make_timing.py --clip=a:b --out=look_tests/clip.json` 写）。
- 你的页面：`look_tests/<名字>/index.html`，遵守页面约定（见 `src/main.js` 开头）。渲染：
  `node render.mjs --page=look_tests/<名字>/index.html --timing=look_tests/clip.json --tag=<名字> --frames`，
  再 `--encode --out=out/look_tests/<名字>.mp4`。联系表、逐帧条、局部同样加 `--page` 和 `--timing`。
- 本机字体：（列出）。需要的字体没有就下载 OFL 字体放进自己目录的新文件夹，连同许可证。
- 构图：（例：字幕的基线在 y 1000 以上，主角和关键文字避开；手机上 1080 宽显示一半大小时字要读得清。）

### 律动（量出来的）
速度、拍号、八分音符间隔；片段里最强的几下（低音重拍、高音重拍，带时间和强度）。不要每一下都一样地动：小东西跟八分音符，冲击给低音重拍，大动作给小节头和最重的那一下。

### 故事节拍（原曲秒数）

| 时间 | 歌词行 | 发生什么 |
|---|---|---|
| a | | 开头已经是完成的画 |
| | | 最重的那一下：这一段的高潮 |

### 人物
（谁；在缩略图大小只看轮廓就分得清男女和身份；属于哪一类片子的长相，要好看。）交一张定妆表：两人大图并排，加上片中实际大小的样子，加上整帧缩到 320 宽的样子。

### 这个方向
画风的描述：材料、颜色、线、光、质感、镜头怎么动。会被拿去和什么比（同类的作品、平台上流行的做法），为什么不会输。

### 交付
- `look_tests/<名字>/` 的页面和源码；`out/look_tests/<名字>.mp4`；整段联系表；定妆表。
- 简短报告：逐拍写片段里发生了什么（带时间）；检查了什么；已知弱点；ms/帧；文件路径。

### 自查
整段联系表；重拍前后的逐帧条（动作落在重拍那一帧）；人物、文字、字幕的原尺寸局部；320 宽缩略图能不能读出故事；确定性；没有黑帧、NaN 帧（渲完看每帧平均亮度）；颗粒；第 0 帧当封面。

预算：第一轮 60–90 分钟。这是选方向用的试片，不是成片。

### 质量要求
- 每个重拍落在它之后的第一帧，满强度。
- 人物要好看：用人物包的表情、眨眼；原尺寸检查手、脚、肘、膝、脖子和每一处接触。

### 交付
两个镜头文件；每镜 12 帧联系表；重拍前后的逐帧条；第一帧原尺寸；简短报告（逐拍、检查了什么、弱点、需要引擎或人物包补什么）。预算约 45–75 分钟。
