## 命令

```bash
npm install
python3 -I tools/analyze_audio.py ...
node render.mjs --frames --workers=3
node render.mjs --encode --out=out/<名字>_rebuild.mp4
```

- 重建和成片是否逐字节相同（依赖的环境：显卡、Chrome、ffmpeg、字体版本）。
- 页面开关（`--q="a=1"`）。

**规模**：帧数；每帧毫秒数和全片渲染时间；代码行数；从开工到成片的小时数；会话记录里的 token 和折合费用（按会话分）。
